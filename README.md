# Cyber Portfolio

Hi, I'm Vishal Reddy — a cybersecurity degree student focused on Governance, Risk, and Compliance (GRC). This repo collects self-directed projects I've built to practice real GRC workflows: risk assessments, policy writing, framework mapping, and audit simulations.

Each project uses a fictional organization as the scenario, follows a named industry framework (NIST, ISO, SOC 2, etc.), and produces the kind of deliverable a GRC analyst would actually be asked to create.
