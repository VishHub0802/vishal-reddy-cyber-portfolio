# Cyber Portfolio

Hi, I'm Vishal Reddy — a cybersecurity degree student building hands-on projects to develop practical skills alongside my coursework. This repo collects self-directed work across different areas of cybersecurity, including GRC, risk assessment, and security documentation, with more categories added as I build them out.

Each project uses a realistic (often fictional) scenario, applies a named industry framework or standard where relevant (NIST, ISO, SOC 2, etc.), and produces the kind of deliverable a working practitioner would actually be asked to create.
